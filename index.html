Current Research

Push Your Agent: Measuring and Enforcing Quantitative Goal Persistence in Long-Horizon LLM Agents

PushBench studies whether long-horizon language agents persist until externally verified completion. The benchmark uses repository-artifact collection with verifier-backed work units and measures repeated work, duplicate submissions, false completion, and progress drift.

Key Results

A state-tracking controller reaches 69-78% success; a backlog-tracking controller reaches 25-50% in settings where standard controllers complete no tasks. Frontier agents including Claude Code and Codex CLI solve many 50-artifact tasks but drop at 100 artifacts.

Core Insight

Quantitative goals stress a different reliability requirement from local task competence: agents must maintain verified progress and stop only when the requested work is complete.
